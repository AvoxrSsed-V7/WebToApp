Web2App CLI

Web2App CLI is the command-line version of Web2App, designed to convert web projects into applications directly from the terminal.

Features

- Simple CLI interface
- Web project to Android app conversion
- Build and package management
- Configurable project settings
- Designed for Termux and Linux environments

Build

Clone the repository, enter the project directory, then run:

python main.py

Follow the CLI menu to select your project and start the build process.

Status

Development / Experimental

Web2App CLI is currently under development. Features and behavior may change over time.
